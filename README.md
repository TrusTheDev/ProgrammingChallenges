# ProgrammingChallenges

Repositorio de retos simples de programación.

## 📌 Descripción

**ProgrammingChallenges** es un repositorio que utilicé para retar a mis amigos y compañeros con un problema que deben solucionar.
Cada carpeta representa un desafío distinto y contiene su enunciado correspondiente.

La idea principal es que cualquier persona pueda:
* Leer el enunciado del reto
* Resolverlo en el lenguaje que prefiera
* Copiar y pegar su solución dentro del archivo del enunciado (según las instrucciones)
* Subir únicamente el archivo con la extensión del lenguaje utilizado para que pueda ser compilado correctamente

Este repositorio está diseñado para ser simple, accesible y enfocado en la práctica.

## 📁 Estructura del repositorio

El repositorio se organiza de la siguiente forma:

```
ProgrammingChallenges/
│
├── Ejercicio-1/
│   ├── enunciado.md
│   └── (tu solución)
│
├── Ejercicio-2/
│   ├── enunciado.md
│   └── (tu solución)
│
└── ...
```

* Cada carpeta representa un reto independiente.
* Dentro de cada carpeta encontrarás un archivo con el enunciado del problema.
* Tu solución debe respetar el enunciado y las indicaciones del ejercicio.

## 🧠 ¿Cómo participar?

1. Entra a la carpeta del ejercicio que quieras resolver.
2. Lee cuidadosamente el archivo del enunciado.
3. Resuelve el problema en el lenguaje que prefieras.
4. Copia y pega tu solución donde se indique en el enunciado (si aplica).
5. Sube únicamente el archivo con la extensión de tu lenguaje:

## ⚙️ Reglas generales

* No modificar el enunciado original del ejercicio.
* Subir solo archivos de código fuente.
* Mantener nombre de archivo bajo tu pseudonimo asociado.
* Escribir código que compile y funcione correctamente.
* Respetar la estructura de carpetas del repositorio.

## 🎯 Objetivo del repositorio

El objetivo de este repositorio es ofrecer retos de programación simples para:

* Practicar lógica
* Mejorar habilidades de resolución de problemas
* Aprender nuevos lenguajes
* Compartir soluciones de forma ordenada
* Divertirse
Actualmente el repositorio cuenta con un ejercicio, pero se irán añadiendo más desafíos con el tiempo si el proyecto gana relevancia e interés.

## 🚀 Futuro del proyecto

A medida que el repositorio crezca, se planea:

* Añadir más retos de distintos niveles
* Clasificar ejercicios por dificultad
* Incorporar más enunciados y categorías
* Facilitar la práctica continua de programación

## 🤝 Contribuciones

Las contribuciones son bienvenidas.
Si deseas añadir nuevos ejercicios o mejorar los existentes:

* Crea una nueva carpeta con el nombre del ejercicio
* Incluye el enunciado claro y bien explicado
* Mantén la coherencia con la estructura del repositorio
